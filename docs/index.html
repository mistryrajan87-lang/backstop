Backstop · CoinMarketCap Real World Assets API

How few issuers is this catalogue made of?

CoinMarketCap publishes its tokenised real-world assets as a list of assets. Every one of those tokens was minted by somebody. Backstop rebuilds the catalogue along that axis and measures, by value, how concentrated it is.

Issuer here means the name CoinMarketCap attributes a token to. Its issuer record carries a name, a website and a token roster — not custody, jurisdiction or a legal entity — so nothing below says who is liable for a token, only whose name is on it.

!

What this measures, and what it does not

  • Not a safety check. Safe would mean reserves audited, the contract sound, redemption possible. CoinMarketCap supplies a name, a ticker and a market-cap field — no attestations, no custody, no redemption terms. Adding a concentration index to that does not add safety.
  • Not a map of who pays you back. That is a legal question — which entity, in which jurisdiction, under which document. The API's “issuer” is a label on a token. For a fund, the sponsor, the tokenisation agent and the fund vehicle are three different answers, and this data distinguishes none of them.
  • Not investment advice, and not a buy list. This is one vendor's catalogue: gold-heavy, missing the large treasury products, with almost half its tokens unpriced. It is not a portfolio view and should not be read as one.

Issuer concentration within each chain

No Real World Assets endpoint carries a chain. Each token does carry a crypto_id, so Backstop takes it across to /v2/cryptocurrency/info for the platform — the only route to this view. Each row is a separate market: concentration among the issuers inside that chain, not the share the chain holds.

Is the asset quoted anywhere off-chain?

quotes/latest returns tradfi_markets beside tokens: the non-token venues quoting the asset, each with an exchange, a ticker and a market URL. These are exchange listings rather than the asset's primary market — a tokenised equity's entry points at a crypto exchange's stock product, not at the exchange the share itself trades on. Read it as is this asset quoted anywhere off-chain, then read the venue split beside it.
